# 新北市路邊停車格位動態歷史資料 v1

將從 TDX 下載的 CSV 原始檔放在**本資料夾**。此 README 會進 Git；同資料夾中的 CSV、壓縮檔等原始資料由 `.gitignore` 排除，避免數百 MB 或 GB 的資料進入 GitHub。

建議檔名：`tdx_newtaipei_onstreet_spot_YYYY-MM-DD.csv`；若實際下載的是壓縮檔，先保留 TDX 原檔名，解壓後再依日期命名。不要改寫原始 CSV；清理後的資料另存處理結果。

下載後請記錄在 `docs/historical-data-plan.md`：日期、來源頁面、筆數、檔案大小、下載前後點數、資料欄位與時間範圍。勿把 TDX 金鑰放入 CSV、檔名或筆記本。

來源：[TDX 歷史服務](https://tdx.transportdata.tw/data-service/historical)。目前尚未下載資料。
