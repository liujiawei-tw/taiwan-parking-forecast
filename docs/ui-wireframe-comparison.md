# 電腦版結果頁低保真草圖比較

更新日期：2026-09-24。狀態：討論用草圖，沒有程式或實際地圖畫面。Sponsor 看過 A／B 對照後，同意以 B「地圖優先＋固定路邊區域摘要＋查看全部結果」作第一版方向；尺寸、詳情面板與標記呈現仍待原型驗證。手機版維持地圖在上、結果清單在下。

兩種方案共用：目的地搜尋候選、起點（裝置位置或手動）、出發時間（預填當下，可改未來）、Google 到目的地的 ETA、目的地方圓直線 300 公尺、路邊／路外只顯示實際收錄類型。路邊機率屬於整個 300 公尺區域，個別格位標記只表示目前回報的狀態。

## A：清單常駐（比較基準）

```text
┌────────────────────────────────────────────────────────────────────┐
│ 搜尋目的地   起點   出發時間   抵達目的地 ETA                       │
├─────────────────────────┬──────────────────────────────────────────┤
│ 300 公尺路邊有位機率     │ 目的地 ◎   300 公尺圈                    │
│ 抵達時 XX%；資料時間     │                                          │
│                         │ 停車場 P   目前有位格位 •                 │
│ 停車場 A：目前／預測    │                                          │
│ 停車場 B：目前／預測    │                                          │
│ 路邊目前空格明細        │                                          │
│ [展開]                  │                                          │
└─────────────────────────┴──────────────────────────────────────────┘
```

使用者不用點地圖即可比較場站，區域機率自然可見；但清單長時壓縮地圖寬度，視覺上較像查詢表而非地圖探索。點清單卡可定位地圖，點標記可標亮清單卡。

## B：地圖優先（Sponsor 接受的方向）

```text
┌────────────────────────────────────────────────────────────────────┐
│ 搜尋目的地   起點   出發時間   抵達目的地 ETA                       │
├────────────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────┐                                       │
│ │ 300 公尺路邊有位機率 XX% │ 目的地 ◎   300 公尺圈                │
│ │ 抵達時／資料時間         │                                       │
│ │ [查看全部結果]           │    停車場 P   目前有位格位 •          │
│ └──────────────────────────┘                                       │
│                                                                    │
│ 點 P → 簡要資訊卡 → [查看詳情] → 側邊面板／完整結果清單            │
└────────────────────────────────────────────────────────────────────┘
```

地圖保留完整空間，使用者能先看相對位置；固定摘要讓核心的區域預測不必等點標記才出現。若要比較多座停車場，按「查看全部結果」打開可排序的完整清單，避免逐一點標記。詳情面板仍是清單，不應只依靠地圖標記提供資訊。

## 三個情境對照

| 情境 | A 清單常駐 | B 地圖優先 | 對 B 的驗收 |
| --- | --- | --- | --- |
| 不點任何標記就想知道路邊有位機率 | 清單頂端直接看到 | 地圖上的固定摘要卡直接看到 | 5 秒內找到機率、抵達時間與資料時效 |
| 比較兩座停車場 | 清單中直接比較 | 按「查看全部結果」打開面板後比較 | 一次操作可同時看兩座，不必逐一關閉標記卡 |
| 找目前回報有位的格位並看路線 | 清單明細連動地圖 | 點格位標記或從全部結果開詳情 | 顯示汽車適用性、取得時間，外部路線不宣稱保留車位 |

## 我建議的結果

電腦版採 B 作第一版畫面方向；保留「查看全部結果」作可比較、可鍵盤使用的正式入口，而非隱藏功能。手機版仍用地圖在上、清單在下，不照搬 B 的點標記才有完整清單。選定標記後的外部格位路線使用 Google Maps／Apple Maps；是否顯示「開始導航」取決於使用者是否明確要立即出發，未來規劃時稱「查看路線」。

尚待原型驗證：摘要卡是否遮住目的地與標記、全部結果面板的寬度、標記密集時分群、路邊沒有有效機率時摘要顯示、手機首屏是否同時露出地圖與第一張結果卡。這些目前不視為已實作或已驗收。
