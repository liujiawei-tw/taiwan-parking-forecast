- 所有資料列都有 `DataCollectTime`；未發現負的 `AvailableSpaces` 或 `AvailableSpaces > TotalSpaces`。

- `TAC00002` 同一停車場含 `SpaceType=1` 與 `SpaceType=5`，不可把兩種車位類型直接混為一般汽車位。各代碼語意需以 TDX 官方欄位定義核對。

## 建模前的處理順序

1. 用官方資料字典確認 `SpaceType`、`ParkingAreaID`、`ServiceStatus`、`FullStatus` 的意義。
2. 選定一個具備足夠滿位／接近滿位事件的停車場與車位類型，保留時間序列，定義去重規則。
3. 檢查每場每類型的時間間隔、缺口與異常跳動，形成資料品質報告。
4. 用時間先後切分訓練／驗證，先比較簡單基準，不將 22 天結果宣稱為跨季節預測能力。
