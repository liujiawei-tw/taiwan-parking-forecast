# 專案總覽

更新日期：2026-09-23。狀態：Sprint 0 草案。

## 產品目標

讓開車者在出發前或途中，了解目的地附近停車場**預計抵達時有車位的可能性**，並看見資料新鮮度和不確定性。產品提供輔助決策，不承諾保留車位。

## 使用者與價值

主要使用者是前往不熟悉目的地、需要比較周邊停車選項的汽車駕駛。價值是降低到場後才發現車位已滿的風險。

## 已同意的方向

- 第一個資料入口是 TDX，目標涵蓋全臺**有提供資料的停車場**。
- 後續加入地方政府免費 API；所有來源先轉成統一資料格式，再對外提供查詢與預測。
- 先討論與驗證資料、架構和流程，暫不寫應用程式。
- Java、Spring Boot、MySQL、JPA、Docker、Git／GitHub 是主要技術方向；Redis 會在資料查詢及額度控制階段加入。IntelliJ IDEA 用於後端，Anaconda／Jupyter 用於後續資料分析。

## 第一版邊界（待 Sponsor 最終確認）

- 第一版同時驗證路邊車格與路外停車場，各先選一個可控制的試點範圍；兩者的資料語意、訓練標籤及預測方法分開，結果可在同一查詢介面呈現。
- 查詢全臺停車資訊不等於承諾每個縣市都有即時資料或可預測資料。
- 預計抵達時間由 Google 路線服務估算，不要求使用者手動輸入；出發點與停車選項的 ETA 粒度仍待設計。
- 前端先做簡單網頁；完整手機 App、車位預約、支付及導航不在第一版。

## 成功判斷

先證明：資料覆蓋率可量化、來源中斷時結果不誤導、TDX 使用量控制在免費額度內、預測在時間切分回測中優於只看當前空位的基準。具體門檻需在資料盤點後訂定。
