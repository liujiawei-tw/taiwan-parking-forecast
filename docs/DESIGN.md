# 地圖介面設計規範

更新日期：2026-10-26。正式方向：使用者選定 Impeccable「臺灣街道圖集」完整手機稿。此規範把該稿的視覺層級轉成可使用真實資料的介面；示意底圖、地址與車位狀態不可作為正式資料。

## 設計意圖

以街區地圖協助正前往目的地的駕駛比較路邊格位與路外停車場。地圖保有主要閱讀面，選取結果在桌面側邊面板或手機底部抽屜展開。詳情卡以目前狀態、距離、ETA 與抵達時預測為主，並保留收費與系統取得時間；品質、官方觀測時間及車種適用性不再占用詳情卡的主要欄位。

## 視覺語彙

- 背景採暖米白 `#f5f1e7`，主要文字採深綠灰 `#173b35`，卡片採暖白 `#fffefa`。
- 主操作採深綠 `#16824b`；占用／已滿採紅 `#c8463d`；未知採金黃 `#c59b20`；路外停車場用藍色 P 標記。
- Google Maps 仍提供實際地圖。不要以生成式插畫取代道路或車位實際位置，也不要把示意稿文字、費率或地址帶入資料。
- 位置按已審查目錄的來源座標顯示；在專案完成實地精度校驗前，不得稱為實測精確位置。

## 地圖密度與互動

- 路邊格位依目前縮放，以 56 CSS 像素鄰近距離合併群聚；格位跨越內部網格邊界時仍合併。群聚標記顯示格位筆數，點選後縮放到其涵蓋範圍。
- Google Maps zoom 21 起逐格顯示。選取清單項目時放大至近距離，且選取中的格位暫不加入群聚，確保詳情與地圖標記相符。
- 點選路邊格位時採 5 公尺地面比例；點選路外停車場時以 37 CSS 像素代表 20 公尺；選取目的地或按回到目的地時採 50 公尺。以中心緯度校正 Web Mercator zoom，限制於 zoom 3–21；Google Maps 原生比例尺會隨縮放顯示實際比例。
- 選取清單項目時，對應標記保留原本狀態色／P 圖示，並以暖白外圈、深綠描邊、柔和陰影及較高圖層突出；取消選取或選取其他項目時恢復一般標記。
- 路外停車場的藍色 P 圖釘採較大的基準尺寸，地圖 zoom 15 以上會隨縮放逐步放大（最高約 27%）；選取外圈同步縮放，圖釘尖端維持對準來源座標。
- 篩選先作用於格位資料，再建立群聚；群聚計數只表示資料筆數，不表示空位數。
- 路外停車場始終以獨立 P 標記表示，不與路邊格位群聚。
- 地圖平移／縮放只讀唯讀 viewport API；不觸發 Routes 計算或官方來源刷新。

## 資料表述

- 狀態同時用文字／符號及顏色呈現；有位、占用、已滿、未知、過期、停止服務與未觀測不能混用。
- 詳情卡先呈現目前狀態，再把預計抵達時間與抵達時預測並列；距離顯示於標題下方，收費與系統取得時間列為次要資訊。資料品質、官方逐筆觀測時間及一般汽車適用性不作為詳情卡欄位。
- 預測區塊與官方目前觀測分開呈現。模型未通過時間外回測與品質門檻時，標示資料不足；若為離線實驗估計，必須簡要說明百分比代表「模型估計抵達時仍有空位的可能性」，並標明未通過正式驗證且不保證有位，不得冒充官方即時空位。
- 來源沒有提供的逐筆時間、費率、位置詳情保持「來源未提供」，不以系統取得時間或推測內容填補。

## 響應式行為

- 桌面保留大面積地圖；目的地搜尋與快速篩選同列，搜尋欄寬度上限 600px，並允許在窄桌面縮小以保留篩選控制項。結果以地圖側邊抽屜展開；桌面標題採較小固定字級。
- 手機優先顯示目的地搜尋、簡短行程操作與地圖；起點／時間設定可收合，查詢結果以固定底部抽屜查看。
- 手機詳情採兩欄欄位，允許文字換行，遵守安全區 inset；頁面不得產生橫向捲動。
- 觸控控制至少保留 40px 操作高度，鍵盤焦點使用可見外框。

## 審查狀態

實作包括視窗 bounds 分頁、縮放式路邊群聚、路外獨立標記、詳情卡 ETA／預測欄位與 RWD 樣式。2026-10-26 production build 成功，並重建本機 Docker Web；在 `http://127.0.0.1:18088/` 已目視確認桌面版 planner、標題、篩選名稱與空狀態詳情卡呈現新版。Vite 開發埠在 sandbox 瀏覽器中不可達；五種視窗尺寸、真實 map marker／sheet 操作、network 事件及有停車資料時的選取卡仍未驗收。路邊 5 公尺縮放受 Google Maps zoom 21 上限約束；路外 37px／20m、路邊選取與 50 公尺目的地互動尚未在有資料的情境中目視確認。
