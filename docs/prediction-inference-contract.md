# 抵達時預測輸入與輸出契約（Sprint 1 草案）

更新日期：2026-09-24。狀態：供 Sponsor 討論的設計提案；模型種類、特徵、最低觀測比例與數值門檻尚未定案，沒有 coding。獨立 collector 只提供離線訓練資料；使用者查詢由主系統自己的官方即時快照供應。

## 共同語意

- 預測發出時刻記為 `asOf`，Google Routes 估計抵達目的地的時刻記為 `arrivalAt`；預測時距是兩者之差。兩者須有明確時區，抵達時刻不可早於發出時刻。模型只可使用 `asOf` 當時已取得的資料，不使用抵達後才知道的車位結果。
- `arrivalAt` 必須來自當次 Google 路線行車時間與使用者選定出發時刻的換算；預測時距只供模型判定特徵與驗證範圍，不是系統另造的 ETA。離線評估可按 10／30／60 分鐘等區間分組，但線上不可把本次 Google ETA 改成固定分鐘數或取整後的時間。無可信預測時只讓機率為空並回原因，Google ETA 不變。
- 目前車位觀測另外保存來源觀測時間、主系統成功取得時間、完整快照版本及品質。若模型需要近期觀測，過期且受控刷新失敗時按已決定規則回「預測資料不足」。快取命中或重新讀取舊來源內容不讓觀測變新。
- 第一版只預測一般汽車。路邊目標是**抵達時整個目的地 300 公尺圓內至少一個合格格位回報空位**的機率；路外目標是**抵達時指定停車場至少一個一般汽車位**的機率。這兩個機率不代表車位已保留或使用者實際到場必然可停。
- 推論輸出至少有目標時間、機率（可空）、可用／資料不足／失敗狀態、原因、模型版本和產生時間；要能追到使用的完整快照版本。官方目前觀測與模型推論分開回傳。

## 路邊區域：候選最少輸入

| 輸入 | 用途與條件 |
| --- | --- |
| 目的地 WGS84 座標、直線半徑 300 公尺、範圍版本 | 定義這次預測的圓與包含哪些格位；訓練標籤須用相同範圍規則建立 |
| `arrivalAt`、`asOf`、預測時距 | 定義要預測的未來時間；逾越模型驗證過的時距時不得硬推 |
| 範圍內已核實的一般汽車格位集合與收錄覆蓋狀態 | 只有完整涵蓋且資格可判定時，才有資格輸出**完整圓形**機率；部分／未知覆蓋按已決定規則暫不輸出 |
| 同一完整快照版本內的有效觀測格位數、目前空格數、應觀測格位數、觀測年齡 | 形成區域特徵並判斷資料品質；不能把未觀測格位算成已滿。最低有效比例待回測設定 |
| 格位在目標時刻的適用條件 | 只有開放／車種／特殊限制能可靠判斷時才納入；無法判定者須在覆蓋與品質中呈現 |

這些是**推論契約所需的資料類別**，不是已核定的模型特徵清單。訓練資料若只按固定路段或固定網格聚合，不能直接宣稱適用任意目的地的 300 公尺圓；須用與線上相同的圓形集合建立訓練標籤，並驗證空間與時間泛化。此點是新莊試點的關鍵 ML 風險。

Sponsor 已確認訓練標籤與線上目的地 300 公尺圓必須對齊；候選樣本生成、時間配對和驗證方法見 `roadside-training-sample-plan.md`。

## 路外單一停車場：候選最少輸入

| 輸入 | 用途與條件 |
| --- | --- |
| 經核對的系統停車場 ID、來源對應 ID、一般汽車資格 | 定義要預測的場站，避免同名場站或不同來源 ID 誤合併 |
| `arrivalAt`、`asOf`、預測時距 | 與該場訓練標籤的時間定義一致 |
| 該場最新有效汽車剩餘位、完整快照版本與觀測年齡 | 候選第一版模型的近期狀態；負數特殊碼、缺值、過期不能當 0 |
| 車場是否在目標時刻營業／適用一般汽車 | 若規則無法可靠判定，不把關閉或限制使用誤當滿位 |

總汽車位數可作候選特徵，但來源未可靠提供時不能捏造。目的地到場站的直線距離用於附近清單，**不等於**該場是否有位的必要特徵。使用者起點、搜尋文字及 Google 路線細節不預設輸入模型；Google ETA 已提供本次預測需要的目標時刻。

## 拒絕預測與待驗證

- ETA 失敗、目標時距超出驗證範圍、模型版本未載入、必要車種／營業資格無法確認、模型所需近期觀測過期且刷新失敗：只回原因，不編造機率。
- 路邊另有完整圓形覆蓋不足／未知、有效觀測比例不足、範圍集合無法與訓練定義對齊等拒絕原因。路外按每場獨立判斷；一場無法預測不抹掉其他場。
- 歷史日曆、星期、時段、節假日、容量比率、天氣等皆是**候選特徵**，不是此階段的必要 API 欄位；只有資料來源可靠、訓練／線上同樣可得，且回測證明有益時才加入。
- 待決：路邊任意圓形的訓練樣本生成與空間驗證方法、有效觀測比例、最大預測時距、模型選型／產物格式、Java 內執行或獨立 Python Docker 推論服務，以及兩類模型的最低回測指標。
