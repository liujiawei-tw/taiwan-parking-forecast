# 地址定位服務評估：TGOS 舊候選

更新日期：2026-09-24。狀態：2026-09-24 暫緩；Sponsor 改以類 Google Maps 的目的地搜尋為方向。尚未呼叫 TGOS 地址定位 API，尚未選定正式供應者。主系統仍未開始 coding。

## 目的與決策界線

第一版讓使用者輸入地址，確認候選地點後，以座標查詢新莊附近停車選項。本輪先評估 TGOS 能否可靠解析新莊地址；「先測 TGOS」不等於已決定用 TGOS 上線。地址定位與停車資料是不同上游服務，各自記錄使用量與錯誤。

## 申請與介接前檢查

TGOS 官方開發人員指南稱 MAP API 申請使用免費，但要先取得 API 金鑰；申請說明要求 TGOS 帳號、線上申請及核准，並以 Domain／IP 識別。需核對地址定位是否屬個人可申請的一般服務、使用的 Web 或 Web Service 版本、前端或後端呼叫方式、測試／正式網域或 IP、使用額度、快取條款與座標系統。沒有核准憑證前，不把公開圖台查詢當成 API 實測；任何金鑰都不進 Git、Issue、Notebook 或本文件。

## 小樣本測試矩陣

| 類型 | 輸入示例／做法 | 應檢查 |
| --- | --- | --- |
| 完整門牌 A | 新北市新莊區中正路176號（新莊區公所） | 是否回到相符門牌、座標是否落在建築附近 |
| 完整門牌 B | 新北市新莊區中華路一段2號（新莊分館） | 中文數字、樓層省略時是否正確解析 |
| 完整門牌 C | 新北市新莊區公園路11號（新莊國民運動中心） | 不同路段結果與座標位置 |
| 不完整輸入 | 新莊區中正路 | 是否回傳多候選／道路中心，前端是否要求使用者確認 |
| 錯字或無效地址 | 使用虛構門牌、明顯錯字 | 不得默默定位到行政區中心後當成精確目的地 |
| 試點外地址 | 新北市板橋區公所公開地址 | 能辨識區外並顯示「目前尚未支援此區」 |

以上完整門牌僅作公開機構測試案例；地址來源見下方連結。測試時記錄：輸入、回傳候選數、標準化地址、原始座標與 CRS、轉成 WGS84 後的位置、匹配／精度資訊、成功或錯誤、延遲。使用公開地圖人工檢查座標位置；門牌附近不等同車輛可停靠的位置。先測少量案例，不以三筆成功推論全新莊準確率。

## 通過條件與後續

完整門牌應能定位到正確的新莊地點，且不能在無精確結果時默默用道路或行政區中心代替；歧義、無結果、服務失敗與區外輸入需能在產品流程中明確區分。若 TGOS 的授權、部署方式或解析品質不適合，再比較其他提供者。正式選型前量測更多地址、解析成功率、位置誤差、延遲與額度；是否可快取需依供應者條款確認。
