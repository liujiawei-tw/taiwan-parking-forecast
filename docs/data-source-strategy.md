# 停車資料來源與預測目標討論稿

更新日期：2026-10-04。新莊區試點與獨立收集器已開始；S3-016 已收斂新莊 MVP 即時來源優先序，預測模型仍需 ETA-aware 標籤、跨來源 canonical mapping 與回測 gate。

## 2026-10-04 S3-016 來源決策

新莊 MVP 的即時停車來源以新北市官方 Open Data 為主：路邊抓全量後以 `areacode=65000050` 篩新莊，路外以靜態 catalog 的 `AREA=新莊區` 取得場站 ID，再 join 即時剩餘位。TDX 保留為未來全臺擴充與交叉驗證來源，但目前不作新莊 MVP 的主要即時來源。

TDX 的限制已實測：NewTaipei 路外基礎 endpoint 目前回空集合；歷史路外 City endpoint 不含 `NewTaipei`；歷史路邊 2026-09-17 至 2026-09-23 city-level metadata 約 5.4 GB，依 20 MB／點粗估約 270 點，且 `ParkingSpotID` server-side filter 實測未能降低資料量。因此本階段不下載完整 TDX raw data，不把 TDX 當新莊路外訓練資料來源。

完整證據與狀態碼對照見 `s3-016-data-source-coverage-decision.md`。

## 使用情境與候選預測標籤

使用者搜尋目的地並輸入預計抵達時間，系統列出附近路邊格位、路段與路外停車場，同時分開顯示「最新觀測狀態」與「抵達時預測」。MVP 候選定義：

- 路邊單格位：原始資料用於區域聚合；第一版不把逐格機率當成主要產品結果。服務停止、設備未知、格位類型不適用時不得直接當作「被占用」訓練。
- 路邊路段／目的地附近範圍：第一輪模型可預測抵達時區域可用格數；產品主要回答 `P(抵達時範圍內至少一個合適格位可停)`。有無至少一格要單獨回測，不可把預測格數大於零直接稱為校準過的機率。範圍半徑先比較資料密度與波動，再決定。
- 路外停車場：第一輪模型可預測抵達時的汽車剩餘位數；產品再評估 `P(汽車剩餘位數 > 0)` 或較保守的風險門檻。要先核對車種、分區與場站總量語意。

以上皆是「在某個抵達時間點可用的機率」，不是保證有車位，也不是車位預約。ETA 可先由使用者輸入分鐘數；導航與位置追蹤留待後續決定。

## 搜尋與接近抵達

1. 搜尋時：從本地最新觀測與歷史模式預測抵達時狀態，顯示資料時間與預測時間。
2. 接近抵達時：使用者重新開啟／手動更新畫面，系統顯示最新已取得的官方觀測；若抵達時間仍在未來，使用新觀測重新計算短期預測。
3. 來源是否已更新由伺服器排程擷取決定。初版不讓每位使用者按更新就各自呼叫上游 API；可在點數和來源更新頻率明確後評估受控、共用的按需更新。
4. 若資料過期或來源中斷，標示時間與狀態；不能把舊觀測或模型輸出說成「剛剛確認有位」。

## 歷史資料成本與其他路徑

TDX 申請頁顯示新北市 2026-08-01 至 08-31 的完整歷史檔已產製，大小 462.6 MB、預估 23.23 點，超過 Sponsor 每月 3 點。2024-04-01 至 2026-07-31 的申請仍在產製，點數未知。**不將購買整月或多年完整檔作為 MVP 前提。**

| 路徑 | 可帶來什麼 | 限制／驗證 |
| --- | --- | --- |
| 已取得的 TDX 單日路邊與 22 日機場資料 | 立即驗證欄位、資料清理與最初基準 | 路邊只有一天，無法證明跨日效果；機場不代表一般市區停車場 |
| 選少量分散日期的 TDX 歷史資料 | 可補平日、週末及不同時段 | 每筆申請前需看預估與剩餘點數；先不追加購買 |
| 新北市官方即時開放資料定期擷取，自建試點歷史 | 免費資料來源；可逐日累積目標區域的歷史與線上查詢資料 | 需要時間累積、遵守平台介接指引；與 TDX ID／狀態碼能否對上須實測；不能回補過去 |
| 以簡單統計基準先展示，後續增加 ML | 可及早完成可測的端到端原型 | 若歷史跨度不足，需誠實標示預測適用範圍與不確定性 |

新北市官方資料開放平臺：[路邊停車空位查詢](https://data.ntpc.gov.tw/datasets/54A507C4-C038-41B5-BF60-BBECB9D052C6)標示每 2 分鐘更新；[公有路外停車場即時剩餘位數](https://data.ntpc.gov.tw/datasets/e09b35a5-a738-48cc-b0f5-570b67ad9c78)標示每 3 分鐘更新；[開發指引](https://data.ntpc.gov.tw/applications)提供 API 格式與大量、高頻介接提醒。資料集免費不等於可以無限制高頻擷取。正式採用前核對使用條款、欄位對應、錯誤處理與實際更新品質。
