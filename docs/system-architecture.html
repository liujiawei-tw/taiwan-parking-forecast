SYSTEM ARCHITECTURE · PROJECT OVERVIEW

台灣停車空位系統架構

上方按五步說明停車查詢，中間依系統層分工，底部另列離線訓練。線上 API 目前讀取的路外模型仍是實驗版；離線訓練不會在使用者查詢時執行。

Redis 與模型的界線：Redis 保存短期 queryId、防重送識別碼，並用短鎖協調官方來源刷新；MySQL 保存停車目錄、已發布快照與來源狀態，附近查詢由 API 直接讀 MySQL。底部 collector 與 `ml-training` 只處理離線資料；目前路外實驗參數檔已放在 API classpath，僅符合條件時輸出 `EXPERIMENTAL`，不代表正式模型通過驗證，也不會在查詢期間訓練或自動發布。

DEPLOYMENT & DELIVERY

基礎設施、技術棧與程式交付

主系統目前部署在 Hetzner 主機（依部署文件記錄）。圖中列出程式與容器設定可確認的技術版本；離線訓練使用 Python 3，但 repo 尚未鎖定 Python 小版本。

讀圖重點：只有 Web 的 `127.0.0.1:8080` 綁在主機 loopback；API、MySQL 和 Redis 不直接對外開埠。MySQL 用 `mysql-data` volume 保留資料。伺服器密碼和 Routes 金鑰放在主機私有 `.env`；瀏覽器地圖金鑰會出現在網頁，因此須限制可使用的網域。
