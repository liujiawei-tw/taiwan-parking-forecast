# 系統架構簡報大綱

- **格式**：單頁 HTML 橫向翻頁簡報，共 9 頁，含封面；最後一頁呈現已選定且有驗證證據的開發案例。
- **風格**：瑞士國際主義版型；配色依現行 `frontend/src/style.css`，暖米白 `#f7f3e9`、深藍灰 `#20394e`、主操作綠 `#08784f`、卡片白 `#fffefa`。路外停車場藍 `#3c6f9e` 僅作資料類別標記。
- **受眾假設**：大學三年級學生；保留必要技術名稱，並用白話解釋元件用途、資料責任與實驗限制。沒有指定演講時間。
- **內容原則**：只呈現已實作範圍；官方目前觀測、資料品質、ETA 與路外實驗估計清楚分開。不加入 Sprint 文字、Hetzner 或未實作功能。
- **圖片**：不另加圖片；使用 Swiss 模板幾何與 Lucide 標記。案例頁使用已登記 S08 對照版型；離線訓練頁使用 S16 六格簡報版型。

## 工程審查重點與證據

- API 路徑依 `ParkingQueryController` 與前端實際呼叫列出；refresh `trigger` 僅接受 `MANUAL_REFRESH`、`VISIBLE_AUTO_REFRESH`。
- 分頁案例依 `docs/current-state.md` 2026-10-25 修復記錄；來源可能將 `size=40000` 限為 1,000/頁；以空頁確認 traversal complete，不能到 max-pages 未完成仍寫入。
- 案例頁呈現問題、完整性修正與三頁驗證結果；138 筆已映射發布、1,243 筆未映射，明示該結果不代表完整新莊覆蓋。
- 9 頁共使用 7 種正文 S 版式；講者備註依穩定 `data-slide-id` 對應。沒有提供分享時長，不填分鐘或自動翻頁秒數。
