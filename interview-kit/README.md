# 全臺停車位抵達預測｜後端工程師面試簡報

## 開啟與操作

直接用瀏覽器開啟 index.html。簡報共六頁，使用鍵盤方向鍵、空白鍵或左右滑動翻頁；Esc 開啟頁面總覽，P 開啟講者模式。講者備忘可在瀏覽器內編輯並依頁面 ID 保存在本機。

## 設計與內容

以產品前端的暖米白、深綠、無襯線字體呈現。架構圖、UML 時序圖和流程圖都由 HTML／SVG 繪製，沒有生成圖片或外部資源依賴。觀眾頁只呈現後端責任邊界、資料流程、技術棧和一組有日期的目錄稽核結果；詳細背景放在講者備忘與專案文件。

本簡報呈現的範圍是新莊 MVP。全臺 TDX 即時來源尚未整合；路外模型仍是實驗性產物。圖上的街區和標記為示意，官方觀測、ETA 與模型估計分開呈現。

## 內容來源

面試簡報依據 docs/current-state.md、後端 Controller／Service／Adapter、資料庫 migration 與 docker-compose.yml 核對。完整事實、日期、限制和驗收紀錄以這些專案文件及實際程式碼為準。
