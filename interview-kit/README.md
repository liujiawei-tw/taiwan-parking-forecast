# 全臺停車位抵達預測｜後端工程師面試簡報

## 開啟與操作

直接用瀏覽器開啟 index.html。簡報共七頁：第 1–5 頁是主簡報，第 6 頁「備用頁 A」說明 AI Agent 協作，第 7 頁「備用頁 B」說明 ML 訓練與准入。第 2 頁右上「完整架構圖」可展開細節，按 Esc 或「關閉」返回。方向鍵、空白鍵或左右滑動翻頁；Esc 開啟總覽；P 開啟講者模式。講者備忘可編輯，並按穩定的 slide ID 保存在本機。

面試主線講完第 5 頁就結束。只在面試官追問 AI 協作或 ML 時，才手動切到對應備用頁。

## 設計與內容

依 guizang-ppt-skill 的橫向簡報、穩定 slide ID、講者備忘與 Presenter validator 工作流整理。沿用產品前端的暖米白、深綠與無襯線字體。流程圖、UML 與架構圖由 HTML/SVG 繪製；沒有外部 CDN、字型、圖片或執行時網路依賴。

第 2 頁主畫面保留三條分層路徑；「完整架構圖」展開由使用者提供的 SVG 詳圖，包含使用端、前端、API、業務服務、來源刷新、儲存、外部服務、離線 ML 與基礎設施。此詳圖嵌入單一 HTML，依實際後端名稱修正例外處理器與刷新端點標示。第 3、4 頁分別深入查詢時序和資料發布閘門。備用頁不屬於主線敘事。

## 範圍與事實邊界

目前是新莊 MVP；全臺 TDX 即時來源尚未整合。parking-data-collector 提供離線歷史素材，不服務查詢或控制主系統刷新。路外模型仍是 EXPERIMENT_ONLY，尚未通過正式模型准入與生產驗證。目錄盤點不代表即時空位或全臺覆蓋。
